# Notes: Morning Light

**Composition:** Original tune for G pentatonic tongue drum. MIT licensed — Heifer Zephyr.
Designed for the Medium 10T configuration (G2–E4). Works also on 12T and 16T.

**Range check:** D3–E4. Uses all 5 pentatonic notes across one-and-a-half octaves.

**Practice tips:**
1. Practice each 4-bar phrase alone before joining them.
2. The half notes (4 eighths = 2 beats) and whole notes (8 eighths = 4 beats) need patience.
3. This is a "complete" piece — record yourself playing it and listen back as a benchmark.
4. After mastering the written version, try improvising freely using the same G pentatonic
   scale — you've now internalized the 5 notes and how they relate to each other.
