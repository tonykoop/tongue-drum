# Pentatonic Play ★☆☆

Exercises to explore your G pentatonic drum freely. No wrong notes!

## Pattern 1: Adjacent pairs
Strike pairs of neighboring tongues slowly:
```
G+A, A+B, B+D, D+E (ascending pairs)
E+D, D+B, B+A, A+G (descending pairs)
```

## Pattern 2: Skip leaps
Play every other tongue:
```
G D, A E, B G (upper), D A, E B
```

## Pattern 3: Octave pairs
```
Low G + High G, Low A + High A, Low B + High B, etc.
```
Octave pairs create a full, resonant sound — these are the "power chords" of the drum.

## Pattern 4: Free improv
Set a slow, steady pace (1 stroke per second). Strike any tongue that calls to you.
Try to return to the root G after every 4 strokes.

**Duration:** 5–10 minutes. This is both practice and music.
